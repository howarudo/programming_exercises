# Notes

<!-- S__r = A_0 + A_1 + ... + A_r -->
$S_r = A_0 + A_1 + ... + A_r$

$$S_r - S_{l-1} = A_l + A_{l+1} + ... + A_r$$

We want to find the number of pairs $(l, r)$ such that $S_r - S_{l-1} \equiv r - l + 1 \pmod{K}$.

Rearranging, when $l > 0$

$$S_r - r \equiv S_{l-1} - (l-1) \pmod{K}$$

Hence, we can have a hashmap with $S_i - i \pmod{K}$ as the key and the number of occurrences as the value


```python
import sys
from collections import Counter, defaultdict, deque

input = sys.stdin.readline
sys.setrecursionlimit(10**6)


def ii():
    return int(input())


def mi():
    return map(int, input().split())


def li():
    return list(map(int, input().split()))


def si():
    return input().strip()


def main():
    NK = li()
    N = NK[0]
    K = NK[1]

    A = li()
    _map = defaultdict(int)
    back_sum = 0
    cur_sum = 0
    _map[1] = 1
    ans = 0
    for i in range(N):
        if i == K - 1:
            _map[1] -= 1
        if i >= K:
            back_sum += A[i-K]
            _map[(back_sum - i + K) % K] -= 1
        cur_sum += A[i]
        _mod = ((cur_sum - i) % K)
        if _mod in _map:
            ans += _map[_mod]
        _map[_mod] += 1
    print(ans)
    return



if __name__ == "__main__":
    main()
```
